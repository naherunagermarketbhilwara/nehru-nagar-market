महत्वपूर्ण:
यह शुरुआती टेम्पलेट है। प्रोडक्ट के नाम, फोटो और कीमत अभी नमूना हैं।
असली प्रोडक्ट फोटो/कीमत जोड़ने के बाद ही ग्राहकों को भेजें।

प्रोडक्ट कैसे बदलें:
1. products.js फ़ाइल खोलें।
2. STORE_PRODUCTS सूची में name, category, price बदलें।
3. image में फोटो का path लिखें, जैसे images/sandal-1.jpg
4. फोटो को images नाम के फोल्डर में रखें (यह फोल्डर आप बनाएं)।
5. बदलाव के बाद साइट पर फाइलें फिर से अपलोड करें।

फ्री में ऑनलाइन प्रकाशित करने का तरीका (GitHub Pages):
1. github.com पर फ्री अकाउंट बनाएं/लॉगिन करें।
2. New repository बनाएं, नाम रखें nehrunagar-market और Public चुनें।
3. इस ZIP की सभी फाइलें और icons फ़ोल्डर repository में अपलोड करें।
4. Repository में Settings > Pages खोलें।
5. Build and deployment में Deploy from a branch चुनें।
6. Branch: main और folder: /(root) चुनकर Save करें।
7. कुछ मिनट बाद GitHub आपको https://USERNAME.github.io/nehrunagar-market/ जैसा फ्री HTTPS लिंक देगा।
   USERNAME आपकी GitHub ID होगी। यह डोमेन खरीदना नहीं है; यह GitHub का मुफ्त subdomain है।

PWA इंस्टॉल:
1. Android मोबाइल में Chrome से प्रकाशित HTTPS लिंक खोलें।
2. Chrome के तीन डॉट मेन्यू में "Install app" या "Add to Home screen" चुनें।
3. ग्राहक को यही लिंक WhatsApp पर भेजें। ग्राहक भी इसे अपने मोबाइल में इंस्टॉल कर सकता है।

सीमाएँ:
- यह अभी वास्तविक cart/payment/inventory/admin dashboard वाला पूर्ण marketplace नहीं है।
- ऑर्डर WhatsApp पर आते हैं; स्टॉक और डिलीवरी आप स्वयं कन्फर्म करेंगे।
- GitHub Pages स्टैटिक होस्टिंग है; ग्राहक के ऑर्डर/डेटा का अलग ऑनलाइन डेटाबेस इसमें नहीं है।
